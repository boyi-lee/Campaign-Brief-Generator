# 03_copywriting-rules.md
## 文案框架庫：各階段對應的寫作結構與技巧

本文件供 AI 在 Phase 4 決定文案方向時使用。
每個框架標註最適合的漏斗層與使用場景。

知識來源：7000萬爆款文案賣貨聖經、文案大師教你精準勸敗術、秒讚、吸金文案寫作力、
故事行銷聖經、愈難賣愈要說故事、品牌的技術和藝術、逼人買到剁手指的77個文案促購技巧

## 一、SCQA 痛點模型
**適用階段**：MOFU 開賣期（主要）、BOFU 衝刺期

全名：Situation（情境）→ Complication（衝突）→ Question（問題）→ Answer（答案）

### 結構示範（高爾夫球桿）

```
情境（S）：每次開球，方向性都是你最大的煩惱
衝突（C）：換過三支桿，問題還是一樣——擊球點不穩
問題（Q）：你需要的不是更努力練習，而是對的工具
答案（A）：Callaway AI 桿面設計，修正偏差最高 23%
```

**文案濃縮版**：
> 「打球 10 年，偏球問題還在？不是你的問題，是桿的問題。」

## 二、3+5 賣點模型
**適用階段**：MOFU 開賣期（商品頁 / EDM 商品區塊）

用三個問題定位商品，再從五個維度找出賣點：

### 三個定位問題
1. 這個商品幫誰解決什麼問題？
2. 為什麼比競品更好？
3. 用了之後生活會有什麼改變？

### 五個賣點維度
| 維度 | 範例（高爾夫球衣） |
|---|---|
| **功能**：解決什麼問題 | 吸濕排汗，讓你在夏季球場保持乾爽 |
| **數字**：量化效果 | 透氣度比棉質提升 3 倍 |
| **對比**：與競品的差異 | 同等功能，售價只有進口品牌的 60% |
| **場景**：使用情境 | 從早場打到下午，全程舒適不悶熱 |
| **情感**：帶來的感受 | 穿上就像職業球員，自信感直接提升 |

## 三、之前 → 之後 → 橋樑（Before / After / Bridge）
**適用階段**：MOFU 開賣期、故事型素材

最直觀的說服結構：描述現況的痛苦 → 描述改善後的美好 → 說明如何達到。

```
之前（Before）：夏季球場悶熱，揮桿到第 9 洞就汗流浹背，
               影響專注力，後九洞成績總是掉分

之後（After）：從第 1 洞到第 18 洞，始終保持清爽，
             注意力集中在桿法上，不在體感上

橋樑（Bridge）：Descente COOL DRY 系列球衣，
               ACTIVE SENSOR® 技術，排汗比普通面料快 60%
```

**最短版本**（適合社群標題）：
> 「打到第 18 洞還能清爽如初？—— Descente COOL DRY 辦到了」

## 四、PAS 框架（問題 → 煽動 → 解決）
**適用階段**：BOFU 衝刺期（最強）、MOFU 後段

全名：Problem（問題）→ Agitate（煽動 / 放大痛苦）→ Solution（解決方案）

PAS 比 BAB 更激進，適合需要快速推動行動的衝刺期素材。

```
問題（P）：活動今天結束，你還沒下單
煽動（A）：下次這個折扣要等一年——而你的裝備已經落後對手整整一季
解決（S）：最後 6 小時，點擊直接帶走已加入購物車的那件
```

## 五、勾魂開場三法則
**適用階段**：所有階段的標題 / 開場

每則素材的第一句話決定受眾是否繼續看。三種有效開場類型：

### 類型一：痛點直刺型
直接說出受眾最想解決的問題。

> 「打了 10 年球，開球偏差還是你的罩門？」
> 「夏季球場，你是否每打到後九洞就開始分心？」

### 類型二：好奇懸念型
提出一個反直覺的問題或事實，讓人想繼續看。

> 「為什麼頂尖業餘球手都在換桿，而不是換教練？」
> 「日本職業球員每季換 3 套球衣，理由跟你想的不一樣」

### 類型三：場景代入型
描述一個受眾熟悉且有感的場景，讓他們自動代入。

> 「禮拜六早上七點，球場第一組出發——你的裝備讓你有信心嗎？」
> 「跟客戶打球的那個早上，裝備的質感就是你的名片」

## 六、故事說服結構（高單價品類專用）
**適用階段**：MOFU 開賣期（EDM / 長文案 / Landing Page）

高單價、低衝動品類（如高爾夫裝備）的消費者不接受硬推銷，
但對有共鳴的故事沒有防禦心。

**來源**：故事行銷聖經（Douglas Van Praet）、愈難賣愈要說故事

### 五段式說服故事結構

```
① 建立情境（Scene）：描述受眾熟悉的球場情境
② 引入衝突（Tension）：揭示一個他們正在面對的問題
③ 點出洞察（Insight）：說一個他們沒想到但認同的真相
④ 帶入商品（Solution）：自然帶入品牌是解決方案
⑤ 號召行動（Action）：清楚的 CTA，降低行動阻力
```

### 應用範例（Callaway 球桿，EDM 主文）

```
① 你打了幾年球，應該有這種感覺：某幾場球打得特別順，
   某幾場就是怎麼打都不對。

② 你歸咎過天氣、草況、睡眠，
   但從來沒有認真懷疑過桿子。

③ 事實上，70% 的業餘球手用的桿子，
   是為「完美擊球點」設計的——但沒有人每次都打到完美擊球點。

④ Callaway AI 桿面設計，是第一支為「真實擊球」而生的桿。
   不管你打到哪裡，都能給你穩定的距離和方向。

⑤ 618 限定，NT$XX,XXX 起。今天下單，5 天內出貨。
   [立即選購]
```

## 七、77 個促購技巧精選（衝刺期文案庫）
**適用階段**：BOFU 衝刺期標題與 CTA
**來源**：逼人買到剁手指的77個文案促購技巧（川上徹也）

### 三大文案基本原則

1. **讓對方認為與自己有關**：用「你」開頭，直接對話
2. **使用強勁有力的字句**：動詞優先、具體數字、避免模糊語言
3. **讓對方心中產生「為什麼？」**：反直覺、出乎意料的切入點

### 衝刺期適用技巧（精選 10 則）

| 技巧 | 範例 |
|---|---|
| **數字具體化** | 「省 NT$5,200」 優於「省很多」 |
| **倒數緊迫** | 「剩 4 小時 37 分」 優於「即將結束」 |
| **否定句翻轉** | 「不換桿，你永遠不會知道差在哪」 |
| **問句引入** | 「你真的要再等一年嗎？」 |
| **對比放大** | 「一頓商務午餐的價格，換一整套球場形象」 |
| **行動動詞 CTA** | 「直接帶走」「一鍵加入」 優於「了解更多」 |
| **已售出數量** | 「今天已有 247 人下單」 |
| **損失語言** | 「你的同伴已經下單了」 |
| **限定感** | 「最後 XX 件」「今天的價格明天就消失」 |
| **保證移除障礙** | 「7 天內不滿意，全額退款，不問原因」 |

## 八、各渠道文案長度與節奏

| 渠道 | 主標字數建議 | 節奏 | 備註 |
|---|---|---|---|
| FB / IG Feed | 15–25 字 | 一句話說完 | 超過 3 行就截斷 |
| IG Story / Reels | 8–15 字 | 1–2 秒內讀完 | 要配合動態節奏 |
| TikTok | 字幕 5–10 字/幕 | 每幕停留 1–2 秒 | 口語化，不用完整句子 |
| EDM 主旨 | 15–30 字 | 包含數字或懸念 | A/B 測試主旨有效 |
| EDM 主標 | 20–35 字 | 可以是完整句子 | |
| PC Banner | 10–20 字 | 3 秒讀完 | |
| Mobile Banner | 8–15 字 | 更短更急 | 小螢幕可見字數限制 |
