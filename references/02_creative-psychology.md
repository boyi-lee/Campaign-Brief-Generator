# 02_creative-psychology.md
## 心理機制庫：各漏斗層對應的說服工具

本文件供 AI 在 Phase 4 選擇訴求切點時使用。
每個心理機制標註適用的漏斗層與活動階段。

知識來源：勾癮、直覺行銷、暗黑行銷術、誰說人是理性的、鉤癮效應、推力行銷、洞悉價格背後的心理戰

---

## 一、鉤癮模式（Hook Model）
**來源**：鉤癮效應（Nir Eyal）
**適用階段**：TOFU 預熱期（建立觸發機制）

讓使用者養成自動回來的習慣，需要完整走過四個階段：

```
觸發（Trigger）→ 行動（Action）→ 獎勵（Variable Reward）→ 投資（Investment）
```

### 行銷活動應用

| Hook 階段 | 活動應用方式 |
|---|---|
| **外在觸發** | 廣告、EDM、社群通知 → 讓潛在受眾知道活動存在 |
| **內在觸發** | 與情緒掛鉤：「每到換季就想更新裝備」的感受 |
| **行動** | 讓點擊進入活動頁的門檻極低（一鍵、直覺、快速） |
| **獎勵** | 不可預期的驚喜：隱藏優惠、限時解鎖、早鳥禮 |
| **投資** | 加入購物車、收藏商品 → 讓受眾為轉換鋪路 |

**素材切點**：預熱期素材的 CTA 不要求立即購買，
要求低門檻「投資」行為（收藏 / 登記 / 追蹤），為開賣期轉化鋪路。

## 二、損失厭惡（Loss Aversion）
**來源**：誰說人是理性的（Dan Ariely）、推力行銷
**適用階段**：BOFU 衝刺期（最有效）、MOFU 後半段

人對損失的敏感程度是同等獲利的 **2–2.5 倍**。

### 兩種框架效果對比

| 獲利框架（效果較弱） | 損失框架（效果較強） |
|---|---|
| 「現在購買省 NT$2,000」 | 「不買就錯過 NT$2,000 的優惠」 |
| 「活動期間享 85 折」 | 「活動結束後恢復原價，差價自付」 |
| 「限時優惠進行中」 | 「你的優惠剩 XX 小時就消失」 |

**素材切點**：衝刺期主標文案優先使用損失框架，而非獲利框架。

## 三、價格錨定（Price Anchoring）
**來源**：洞悉價格背後的心理戰（William Poundstone）
**適用階段**：MOFU 開賣期（核心技術）

消費者不知道商品「應該」值多少，
他們靠**相對比較**來判斷價格是否划算，而不是絕對金額。

### 錨定技術

**高錨定**：先顯示高價，再顯示優惠價
> 「原價 NT$18,000 → 618 特惠 NT$12,800」
> 讀者先接受 18,000 的錨點，12,800 感覺極划算

**競品錨定**：與同類高價品牌比較
> 「同等規格進口品牌要價 NT$25,000，[品牌名] 只需 NT$15,800」

**套組錨定**：顯示單買總價 vs 套組價
> 「單買：NT$28,000 / 套組購：NT$19,800，省下 NT$8,200」

**數字 9 效應**：NT$1,990 比 NT$2,000 感覺便宜得多
（消費者記憶的是第一個數字：1 vs 2）

**素材切點**：開賣期素材必須「先顯示高錨點，後顯示優惠價」，
禁止只顯示優惠價而不顯示原價。

## 四、稀缺原則（Scarcity）
**來源**：推力行銷、直覺行銷
**適用階段**：BOFU 衝刺期、MOFU 後段

稀缺感製造兩種效果：
1. 知覺品質上升（「稀少的東西通常是好東西」）
2. 行動緊迫感上升（「不搶就沒了」）

### 兩種稀缺類型

**時間稀缺**：限時，對決策拖延者有效
> 「今晚 24:00 截止」「剩最後 6 小時」

**數量稀缺**：限量，對猶豫者有效
> 「僅剩 3 件」「限量 50 組，已售出 47 組」

### 使用原則
- 稀缺感必須真實或可驗證，否則傷害品牌信任
- 高端品牌用「限量」比用「倒數計時」更符合品牌調性
- 數量稀缺加上已售出比例，效果更強（社會認同 + 稀缺雙效）

## 五、社會認同（Social Proof）
**來源**：直覺行銷（Mathew Dixon）
**適用階段**：MOFU 開賣期（降低猶豫）

人在不確定時，傾向跟從多數人的選擇。

### 社會認同素材形式

| 形式 | 範例 |
|---|---|
| 數字型 | 「本季已有 3,200 名球友選擇」 |
| KOL 型 | 「職業球員 [姓名] 指定配備」 |
| 媒體背書 | 「Golf Digest 年度最佳推薦」 |
| 用戶評價 | 五星評價截圖 + 真實姓名縮寫 |
| 銷售排行 | 「本站 #1 熱銷球桿」 |

**素材切點**：開賣期輪播素材的最後一張或 EDM 中段放社會認同，
降低受眾的「只有我在考慮這個嗎？」的孤立感。

## 六、Nudge 推力（選擇架構）
**來源**：推力行銷（理查‧塞勒 Nudge 理論應用）
**適用階段**：全階段，但衝刺期最關鍵

Nudge 不是強迫，而是「讓正確選擇變成最省力的選擇」。

### 電商活動常用推力

| 推力類型 | 應用方式 |
|---|---|
| **預設選項** | 套組預設勾選，單買需要主動取消 |
| **預設數量** | 加入購物車預設數量 2（非 1） |
| **社會比較** | 「90% 的球友選擇完整套組」|
| **損失框架** | 按鈕文字改為「不讓我錯過優惠」而非「立即購買」 |
| **選擇簡化** | 只推薦 3 款，不讓受眾面對 30 款的選擇麻煩 |

**素材切點**：Landing Page 版面設計的 Brief 要特別標注 Nudge 元素的位置，
讓設計師在排版時預留這些功能性空間。

## 七、11 種人性直覺（Direct to Action）
**來源**：直覺行銷（Mathew Dixon）
**適用階段**：各階段訴求設計

消費者靠直覺做決定，靠邏輯事後合理化。
素材設計要先打中直覺，再提供邏輯支撐。

### 與活動素材最相關的 5 種直覺

| 直覺 | 素材切點 |
|---|---|
| **比較直覺** | 並排顯示 Before/After、原價/現價、競品/本品 |
| **掌控直覺** | 「你來決定要哪款配置」而非「我們幫你搭配好了」 |
| **互惠直覺** | 早鳥免費贈品、加購優惠，讓受眾感覺「賺到了」 |
| **稀缺直覺** | 見第四節「稀缺原則」 |
| **社群直覺** | 見第五節「社會認同」 |

## 八、情感決策優先原則
**來源**：暗黑行銷術、誰說人是理性的
**適用階段**：全階段

消費者**因情感而購買，用邏輯事後合理化**。
素材設計的順序：先觸動情感，再提供理性依據。

### 情感先、邏輯後的素材結構

```
① 情感觸發（引發感受）：「在球場上，裝備就是你的第一印象」
② 欲望強化（具體化想像）：球場情境大圖，模特身著品牌完整造型
③ 邏輯支撐（理性購買依據）：「AI 桿面設計，擊球偏差減少 23%」
④ 行動觸發（降低阻力）：「618 限定，今天入手」
```
