# 04_channel-specs.md
## 渠道規格：尺寸、格式、版本規範

本文件供 AI 在 Phase 4 列出素材規格時使用。
最後更新：2026 年 5 月（請定期核對各平台官方規格）

---

## 一、社群廣告：FB / IG

### 1-1 Feed 方形（主力格式）
| 項目 | 規格 |
|---|---|
| 尺寸 | 1080 × 1080 px（1:1） |
| 格式 | JPG / PNG（靜態）、MP4（動態） |
| 動態時長 | 最長 60 秒，建議 15–30 秒 |
| 安全區 | 四邊各留 50px，避免文字被裁切 |
| 檔案大小 | JPG/PNG 最大 30MB；MP4 最大 4GB |
| Retina 版 | 輸出 @2x（2160 × 2160）供高解析使用 |
| 備註 | 文字覆蓋面積建議 ≤ 20%（FB 廣告政策） |

### 1-2 Feed 橫版（連結廣告常用）
| 項目 | 規格 |
|---|---|
| 尺寸 | 1200 × 628 px（1.91:1） |
| 格式 | JPG / PNG |
| 安全區 | 上下各留 100px，左右各留 50px |
| 備註 | 常用於 FB 連結預覽圖、PC 端顯示效果最佳 |

### 1-3 IG Story / Reels（直版）
| 項目 | 規格 |
|---|---|
| 尺寸 | 1080 × 1920 px（9:16） |
| 格式 | JPG / PNG（靜態）、MP4（動態） |
| 動態時長 | Story 最長 60 秒；Reels 最長 90 秒 |
| 安全區（上方） | 頂部留 250px（避免被 Story 頭像遮蓋） |
| 安全區（下方） | 底部留 250px（避免被互動按鈕遮蓋） |
| 主要視覺區 | 安全區間的 1080 × 1420px 中央區域 |
| 檔案大小 | 靜態 30MB 以內；動態建議 50MB 以內 |

### 1-4 FB / IG 輪播（Carousel）
| 項目 | 規格 |
|---|---|
| 尺寸 | 每張 1080 × 1080 px（1:1） |
| 張數 | 2–10 張 |
| 格式 | JPG / PNG（每張可不同） |
| 備註 | 第一張最關鍵，決定受眾是否左滑；最後一張放總 CTA |

## 二、TikTok 廣告

### 2-1 In-Feed 廣告（主力格式）
| 項目 | 規格 |
|---|---|
| 尺寸 | 1080 × 1920 px（9:16）為主；1:1 或 16:9 亦可 |
| 格式 | MP4 / MOV |
| 時長 | 5–60 秒，建議 15–30 秒 |
| 安全區（上方） | 頂部留 130px |
| 安全區（下方） | 底部留 370px（互動區） |
| 主要視覺區 | 1080 × 1420 px 中央區域 |
| 檔案大小 | 最大 500MB |
| 備註 | 純靜態圖效果明顯弱於動態，TikTok 優先出動態素材 |

## 三、EDM 電子報

### 3-1 EDM Header Banner（主視覺）
| 項目 | 規格 |
|---|---|
| 尺寸 | 600 × 250–300 px（寬度固定 600px，高度可調） |
| 格式 | JPG（壓縮至 150KB 以內，確保載入速度） |
| Retina 版 | 輸出 @2x（1200 × 500–600），HTML 設定 width="600" |
| 備註 | 不同 Email 客戶端渲染差異大，避免文字嵌入圖片中 |

### 3-2 EDM 商品區塊（品牌 / 商品分區）
| 項目 | 規格 |
|---|---|
| 尺寸 | 600px 寬，高度依內容（單商品建議 200–250px） |
| 格式 | JPG / PNG |
| 備註 | 商品圖建議白底或淺色背景，文字另外用 HTML 排版 |

### 3-3 EDM CTA 按鈕
| 項目 | 規格 |
|---|---|
| 尺寸 | 建議 180 × 44 px 以上（手機觸控友善） |
| 格式 | HTML 按鈕（非圖片，確保部分客戶端圖片停用時仍可見） |
| 備註 | 按鈕顏色與背景對比度至少 4.5:1（無障礙標準） |

### EDM 主旨行
| 類型 | 規格 |
|---|---|
| 主旨長度 | 35–50 字元（手機端顯示約 35 字元） |
| Preview Text | 額外的 50–90 字元預覽文字（緊接主旨顯示） |
| 備註 | A/B 測試：版本一加數字優惠，版本二加懸念問句 |

## 四、官網 Banner

### 4-1 PC Hero Banner（首頁主視覺）
| 項目 | 規格 |
|---|---|
| 尺寸 | 1920 × 600 px（常見比例）或 1440 × 540 px |
| 格式 | JPG / WebP（WebP 檔案更小，載入更快） |
| 安全區 | 中央 1200px 內放主要視覺與文字（兩側可被切掉） |
| 倒數計時器位置 | 標注計時器放置區域（前端工程師接 JS） |
| 備註 | 同時提供不含文字的底圖版本，方便前端疊加 HTML 文字 |

### 4-2 Mobile Banner
| 項目 | 規格 |
|---|---|
| 尺寸 | 750 × 400 px 或 1:1 方形 |
| 格式 | JPG / WebP |
| 備註 | 不可與 PC 版直接裁切，需重新構圖，確保主要元素在手機可讀 |

### 4-3 品牌 / 分類 Banner（活動頁品牌區塊）
| 項目 | 規格 |
|---|---|
| 尺寸 | 600 × 300 px 或 580 × 260 px |
| 格式 | JPG / PNG |
| 備註 | 每個品牌各一張；包含品牌 Logo + 主推商品 + 折扣標示 |

## 五、Landing Page 版面

### 5-1 PC 版
| 項目 | 規格 |
|---|---|
| 版面寬度 | 最大 1440px，內容區 1200px |
| 輸出方式 | Figma Frame 或 Adobe XD，含 Prototype 連結 |
| 交付格式 | 設計稿 + 標注稿（給前端工程師） |
| 必要區塊 | Hero → 活動說明 → 品牌分區 → 商品推薦 → CTA → FAQ |

### 5-2 Mobile 版（必須同時出稿）
| 項目 | 規格 |
|---|---|
| 版面寬度 | 375px（iPhone SE）或 390px（iPhone 15 標準） |
| 備註 | 字體最小 14px，CTA 按鈕最小 44px 高（手指點擊舒適區） |

## 六、各渠道素材版本數量參考

| 渠道 | 每個活動階段建議版本數 | 備註 |
|---|---|---|
| FB / IG Feed 方形 | 1 版主視覺 + 1 版商品版 | 共 2 版 |
| FB / IG Feed 橫版 | 1 版 | 由方形主視覺改裁 |
| IG Story / Reels | 靜態 1 版 + 動態 1 版 | 動態為選配 |
| TikTok | 1 版動態（15–30 秒） | 純靜態不建議 |
| EDM | Header 1 版 + 各品牌商品區塊各 1 版 | 依品牌數量疊加 |
| PC Banner | 1 版 | |
| Mobile Banner | 1 版（重新構圖，非裁切） | |
| Landing Page | PC + Mobile 各 1 版 | |
